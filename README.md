# Wrestling Talent AI — демо-версия (этап 0)

Платформа отбора молодых борцов Туркменистана: тест на телефон с анализом движения, кабинет тренера, турниры и рейтинги, трансляции, магазин экипировки и спортпита. Три языка: туркменский, русский, английский.

Эта версия собрана для показа федерации. Всё, что не подключено по-настоящему, помечено в интерфейсе как «Демо».

## Как открыть

**В интернете:** после включения GitHub Pages сайт открывается по адресу `https://hanchik000.github.io/wrastling/`.

**На своём компьютере:** нужна только папка проекта, установка пакетов не требуется.

```bash
cd wrastling
python3 -m http.server 8080
# открыть http://localhost:8080
```

Камера в браузере работает только через `https://` или `localhost`.

## Что работает по-настоящему

- Запись теста с камеры телефона: отсчёт, таймер, проверка освещения, загрузка из галереи.
- Шесть борцовских тестов: спраул, проходы в ноги, вставание на мост, забегания на мосту (14+, с тренером), подтягивания, челночный бег 3×10 м.
- Анализ движения на устройстве: модель MediaPipe Pose размечает 33 точки тела. Система считает повторения спраула, проходов и подтягиваний, уровень прохода, темп, спад к концу, время на мосту, время челночного бега и развороты. Неполные повторения не засчитываются. Время по секундомеру и круги на мосту вносит тренер.
- Разметка скелета поверх видео, оценка качества съёмки, подсказки «что улучшить».
- Кабинет тренера: очередь видео, подтверждение повторений, оценка техники, комментарий, рекомендация к просмотру. Блок «Из чего сложилась оценка» объясняет каждую цифру.
- Регистрация по телефону, анкета спортсмена, согласие родителя для детей до 18 лет.
- Рейтинги «Лучшие среди детей» и «Лучшие среди взрослых» с фильтрами. У детей только имя, первая буква фамилии и регион.
- Магазин: каталог, размеры и цвета, корзина, оформление с оплатой при получении, проверка 18+ для спортпита.
- Три языка с переключением на лету, шрифты с туркменскими буквами лежат в проекте.

## Важно для Туркменистана

Модель анализа сейчас загружается с `cdn.jsdelivr.net` и `storage.googleapis.com`. Если они заблокированы, приложение честно покажет «Анализ не выполнен» и сохранит видео для тренера. На этапе 1 файлы модели (около 10 МБ) нужно положить на свой сервер. Путь задаётся в `assets/js/pose.js`.

## Структура

```
index.html                 точка входа
assets/css/tokens.css      дизайн-токены: цвета, шрифты, отступы, движение
assets/css/app.css         компоненты и экраны
assets/fonts/              Oswald и Inter (OFL), латиница + туркменские буквы + кириллица
assets/js/main.js          каркас и маршрутизация (#/адреса)
assets/js/i18n.js          языки
assets/js/locales/         тексты tk / ru / en
assets/js/store.js         хранилище (на этапе 1 заменяется API)
assets/js/pose.js          анализ движения и отрисовка скелета
assets/js/motion.js        анимация Motion Intelligence и образцы упражнений
assets/js/data.js          справочники и демо-данные
assets/js/views/           экраны
```
